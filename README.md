## Introduction
This project is part of my Week 2 Cybersecurity Internship at Networkwalks.

In this project, I performed practical activities related to Footprinting, Reconnaissance, Information Gathering and Network Scanning using different cybersecurity tools.

## Objectives
- To understand Footprinting and Reconnaissance.
- To collect publicly available domain information.
- To identify website technologies.
- To check HTTP response headers.
- To perform public information gathering.
- To understand network discovery and topology.

## Tools Used
1. Kali Linux
2. WHOIS
3. WhatWeb
4. Curl
5. Wafw00f
6. theHarvester
7. Google Hacking Database (GHDB)
8. Zenmap / Nmap

## Practical Activities

### Module 1: Footprinting and Reconnaissance
- Domain information gathering using WHOIS.
- Website technology identification using WhatWeb.
- HTTP header checking using Curl.
- WAF detection attempt using Wafw00f.
- Public information gathering using theHarvester.
- Learning about Google Hacking Database.

### Module 2: Network Scanning
- Network discovery.
- Identifying devices in the network.
- Observing IP address information.
- Understanding network topology.

## Learning Outcomes
- Learned basic footprinting techniques.
- Practised different Kali Linux tools.
- Understood domain information gathering.
- Learned website technology identification.
- Understood basic network scanning.
- Learned the importance of authorized security testing.
